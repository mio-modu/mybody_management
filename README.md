# 마이바디 — 내 몸 관리 PWA

**배포됨** — 앱 <https://mybodymanagement.vercel.app> · 소개 페이지 <https://mybodymanagement.vercel.app/landing/>
기본 브랜치에 푸시하면 베르셀이 자동으로 다시 배포한다.

> 예전 GitHub Pages 주소는 **안내 페이지로 바뀌었다.** 기록은 주소(도메인)마다 따로 저장되므로
> 두 주소가 동시에 살아 있으면 설치한 곳에 따라 기록이 갈라진다. 그래서 한 곳만 남겼다.

체중 **68kg**, 혈당, 콜레스테롤, 그리고 **목·허리 통증**을 한 화면에서 관리하는 개인용 PWA.
설치형 앱스토어 배포가 아니라, 내 폰 홈 화면에 올려놓고 쓰는 개인 도구다.

- 빌드 도구·패키지·서버 없음. 정적 파일만으로 동작한다.
- 모든 기록은 **내 브라우저 안(localStorage)** 에만 저장된다. 서버로 전송되지 않는다.
- 오프라인에서도 열리고 기록된다(Service Worker).

---

## 핵심 설계: 묻고 → 판단하고 → 조절한다

기능을 늘리는 대신, 매일 반복되는 이 루프 하나만 정확히 돌아가게 만들었다.

| 단계 | 어디서 | 하는 일 |
|---|---|---|
| **묻는다** | 홈 화면 "체크인" | 지금 시간대에 아직 답하지 않은 2~4개만 묻는다. 아침엔 체중·공복혈당·목/허리, 낮엔 식후혈당·앉은 시간, 저녁엔 통증·처방 운동·걸음 |
| **판단한다** | 통증 화면 | NRS 0~10 점수를 4단계(강화 / 가동성 / 진정 / 보호)로 나누고, 최근 3회 평균이 올라가는 중이면 **자동으로 한 단계 낮춘다** |
| **조절한다** | 오늘의 처방 | 그 단계에 맞는 운동·횟수·이유가 바로 나온다. 유발 요인(앉은 시간, 모니터, 수면 자세…)에 맞춘 "오늘 바꿀 것"도 함께 |

적색신호(팔다리 저림/힘빠짐, 대소변 장애, 발열, 외상, 야간통)를 체크하면 운동 처방 대신
**진료를 먼저 보라는 경고**를 띄운다. 자가 운동으로 다룰 범위를 넘는 신호이기 때문이다.

## 여러 사람이 쓸 수 있다

처음 열면 **1분 온보딩**이 뜬다. 이름·키·목표 체중을 받고, 무엇을 관리할지 고르게 한다.

- **관리 모듈** — 체중(기본) / 혈당 / 혈액검사·혈압 / 통증. **끈 모듈은 탭·체크인·미션·리포트에서 통째로 사라진다**
- **아픈 곳** — 목·허리·어깨/등·무릎 중 선택. 고른 부위만 묻고, 부위별로 처방이 따로 나온다
- **프로필** — 설정에서 추가하면 한 기기에서 여러 명이 각자 쓴다. 목표·기록·포인트가 완전히 분리된다

혈당을 끄면 혈당 탭이 사라지고, 오늘의 미션도 그에 맞게 바뀐다. 쓰지 않는 기능이 자리를 차지하지 않는다.

> 제품으로 키울 때의 단계·수익·의료 경계선·측정 지표는 **[PRODUCT.md](./PRODUCT.md)** 에 정리했다.

## 운동을 모르는 사람도 그대로 따라 하게

"데드버그 좌우 8회 × 3세트" 라고만 적어 두면 아무도 못 한다. 운동 이름을 누르면 펼쳐진다.

- **자세 그림** — 시작 자세를 옆모습 선 그림으로. 어디에 어떻게 자리 잡는지부터
- **단계 3~4개** — 길면 안 읽으므로 그 이상 쓰지 않는다
- **이 느낌이면 맞다** — 제대로 하고 있는지 스스로 판정할 기준
- **흔한 실수** — 가장 많이 틀리는 것 하나
- **영상으로 보기** — 눌러 두면 그 운동의 영상 검색으로 간다

아는 사람에게는 군더더기다. **설정 → 내 몸 설정 → 운동 설명**을 끄면 펼치기 자체가 사라진다.

### 하루에 할 수 있는 양만

예전에는 한 번에 14개가 떴다. 그걸 다 할 사람은 없다. 지금은

- **가장 아픈 부위 3개 + 나머지 부위 2개씩, 전체 6개 상한**
- 맨 위에 **"5가지 · 약 13분"** 으로 오늘 치르는 값을 먼저 보여준다
- 잘려 나간 것은 버리지 않고 **"여유 있으면 더"** 로 접어 둔다
- **0점인 부위는 아예 안 나온다.** 안 아픈 곳이 아픈 곳의 자리를 뺏지 않는다

### 도구가 필요한 운동은 뺐다

밴드·폼롤러·온열팩은 당장 없는 사람이 대부분이고, 없으면 그 줄은 건너뛰게 된다.
전부 **맨몸 + 의자 + 벽 + 수건**으로 되는 동작으로 바꿨다
(밴드 로우 → 수건 당기기, 폼롤러 흉추 신전 → 의자 등받이 흉추 펴기, 온열 후 회전 → 가벼운 목 회전).

## 입력이 귀찮지 않게

기록 앱이 죽는 가장 큰 이유는 입력 마찰이다. 가장 귀찮은 두 가지를 먼저 없앴다.

**검진 결과지 → 붙여넣기 한 번.** 문자·앱·PDF에서 결과를 복사해 붙여넣으면 14개 항목과 검사일이
자동으로 채워진다. 병원마다 다른 표기(`LDL-콜레스테롤` / `LDL-C` / `저밀도지단백`)를 전부 알아듣고,
`(0~130)` 같은 참고범위나 `<200` 같은 기준치는 걸러낸다. 못 읽은 항목만 직접 치면 된다.

**종이 결과지뿐이라면** 사진을 띄워 놓고 입력한다. 사진은 화면에 보이기만 할 뿐
앱에 저장되지도, 어디로 전송되지도 않는다.

> 통증 점수만은 끝까지 손입력으로 남겼다. 센서가 못 재고, 그날 몸을 한 번 돌아보게 만드는 것 자체가 기능이다.

## 병원에 들고 갈 한 장

리포트 → **진료용 요약 1장**. 최근 90일을 A4 한 장으로 정리한다.

- 체중 — 시작 → 현재(7일 평균) → 목표, 30일 변화, BMI, 허리둘레
- 혈당 — 측정 시점별 횟수·평균·최저~최고·목표 범위 내 비율, 추정 당화혈색소
- 검사 — 최근/이전 2회 비교와 변화량, 중성지방/HDL 비
- 통증 — 부위별 7일·30일 평균과 최고, 내가 꼽은 유발 요인, **적색신호를 체크한 날**
- 추세 그래프 2개, 복약·참고 사항

판정하거나 진단하는 문장은 한 줄도 쓰지 않는다. 마지막 줄에 "사용자가 직접 입력한 값이며
판독은 진료하시는 분께 맡긴다"고 적어 둔다. 인쇄 화면에서 PDF로 저장하면 그대로 보낼 수 있다.

## 보상 — 매일 미션을 해내면 나에게 돌아오는 것

**오늘의 미션 3개**만 채우면 그날은 성공이다. 루틴 9개를 다 할 필요 없다.

1. 몸 상태 한 번 기록 (고른 부위 점수 1회)
2. 루틴 5개 이상 체크
3. 숫자 1개 이상 (체중 또는 혈당)

통증 관리를 꺼 두면 1번이 빠지고 "움직임 기록(걸음·물)"이 들어간다. 미션은 항상 3개다.

| 규칙 | 값 |
|---|---|
| 미션 3개 달성한 하루 | **+10p** |
| 연속 7일마다 | **+30p 보너스** |
| 포인트로 바꾸는 것 | 설정에 내가 직접 적어둔 **실제 보상** (디저트·영화·마사지…) |

**포인트는 체중이나 혈당 수치에 걸지 않는다.** 기록과 루틴 — 내가 통제할 수 있는 행동에만 건다.
수치는 수면·생리주기·소금 섭취에 따라 흔들리므로, 거기에 보상을 걸면 과속하거나 일찍 포기하게 된다.
숫자가 나쁜 날에도 기록만 하면 그날은 성공이다.

리포트 화면에 **연속일 · 4주 스탬프 · 뱃지 12종**이 있고, 홈 맨 위에 오늘 미션 링이 있다.
뱃지는 결과(−1kg, 목표 도달, 혈당 안정)도 축하하지만 포인트로는 바뀌지 않는다.

> 보상은 **실제로 받아야** 작동한다. 포인트만 쌓고 넘어가면 다음 주부터 미션이 의미를 잃는다.

## 설치해서 쓰기

### 1. 어딘가에 올린다 (셋 중 하나)

**Vercel — 주력 배포처**

저장소에 `vercel.json` 과 `.vercelignore` 가 들어 있어 추가 설정이 필요 없다.
처음 연결할 때만 이렇게 한다.

1. <https://vercel.com/new> → **Import Git Repository** → `mybody_management` 선택
2. Framework Preset `Other`, Build Command·Output Directory **모두 비워 둔 채** → **Deploy**
3. `https://<프로젝트명>.vercel.app/` 에 앱이, `/landing/` 에 소개 페이지가 뜬다

그 뒤로는 푸시할 때마다 자동으로 다시 배포된다.
다른 주소를 쓰게 되면 `js/config.js` 의 `APP.siteUrl` 을 그 주소로 바꾼다 —
앱 안의 **공유 링크**가 이 값을 쓴다. 빈 문자열로 두면 지금 열려 있는 주소를 쓴다.

`vercel.json` 이 하는 일 — 서비스워커·HTML·JS·CSS 는 항상 최신을 받게 하고(`must-revalidate`),
아이콘과 스크린샷만 1년 캐시, 매니페스트 MIME 타입 지정, 기본 보안 헤더 3종.
`.vercelignore` 는 문서·워크플로처럼 사이트 동작과 무관한 파일을 올리지 않는다.

**예전 GitHub Pages 주소**

`.github/workflows/pages.yml` 은 이제 앱이 아니라 `moved/` 의 **안내 페이지**를 올린다.

- 새 주소로 가는 버튼
- 그 주소에 기록이 남아 있으면 **"기록 내려받기"** 버튼이 뜬다 (새 주소에서 가져오기로 이어 쓴다)
- `moved/sw.js` 는 **스스로를 걷어내는 서비스워커**다. 예전에 설치한 사람은 캐시된 옛 앱이
  계속 떠서 안내를 못 보게 되는데, 이 파일이 다음 접속에서 캐시와 등록을 지우고 화면을 새로 고친다

**내 컴퓨터에서만**
```bash
python3 -m http.server 8765
# http://localhost:8765 접속
```
> `file://` 로 직접 열면 ES 모듈과 Service Worker가 막힌다. 꼭 http로 열 것.

### 2. 홈 화면에 앱으로 설치 — **기록보다 먼저**

앱을 열면 맨 위에 설치 안내가 뜬다. 안드로이드는 버튼 한 번, 아이폰은 두 단계다.

- **Android (Chrome)**: 안내의 **홈 화면에 앱으로 설치** 버튼 → 끝
- **iPhone (Safari)**: 공유 버튼(↑) → `홈 화면에 추가` → `추가`

> **아이폰은 설치를 먼저 하세요.** iOS 는 사파리와 홈 화면 앱의 저장 공간이 분리되어 있어서,
> 사파리에서 먼저 기록하면 설치한 앱에서는 그 기록이 보이지 않는다.
> 이미 사파리에 기록이 쌓였다면 설정 → 백업으로 내보낸 뒤 설치한 앱에서 가져오면 된다.

설치하면 주소창 없이 전체 화면으로 열리고, 비행기 모드에서도 기록된다.
홈 화면 아이콘을 길게 누르면 **통증 · 혈당 · 체중** 기록으로 바로 가는 바로가기가 나온다.

남에게 보낼 때는 설정 → **공유 → 소개 링크 보내기**. 메신저에 파일로 보내야 한다면
`landing/index.single.html` 한 장을 보낸다(색과 이미지가 파일 안에 들어 있어 혼자 열어도 그대로 보인다).

추가하면 주소창 없는 전체 화면 앱으로 뜨고, 오프라인에서도 열린다.

---

## 처음 1분 세팅

앱을 처음 열면 온보딩이 안내한다 — 이름·키·지금 체중·목표 체중, 관리할 모듈, 아픈 곳.
그 다음 두 가지만 더 하면 끝이다.

1. 검사 화면에 **가장 최근 건강검진 숫자**를 한 번 넣기 (여기가 출발 좌표가 된다)
2. 통증 화면에서 점수 한 번 기록 → 바로 오늘의 처방이 생긴다

그 다음부터는 홈 화면 체크인만 따라가면 된다. 목표치는 설정에서 언제든 바꾼다.

---

## 알림에 대한 솔직한 설명

서버 없는 PWA라서 **앱이 열려 있는 동안에만** 알림이 뜬다(설정에서 시각 지정 + 권한 허용).
확실히 챙기려면 **휴대폰 기본 알람을 아침·낮·저녁 시각에 맞춰두고, 알람이 울리면 앱을 열어** 체크인하는 방식이 낫다.
홈 화면 아이콘을 길게 누르면 통증/혈당/체중 기록으로 바로 가는 바로가기도 있다.

## 백업

데이터는 이 브라우저 안에만 있다. 브라우저 데이터를 지우거나 기기를 바꾸면 사라진다.

- 설정 → **JSON으로 내보내기** (주 1회 권장)
- 새 기기에서 설정 → **파일에서 가져오기** (합치기 / 전체 교체 선택 가능)

## 내 몸에 맞게 고치기

거의 모든 개인화는 `js/config.js` 한 파일에 모여 있다.

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 목표 수치 기본값 | `DEFAULT_TARGETS` (설정 화면에서도 변경 가능) |
| 통증 부위 추가/삭제 | `PAIN_AREAS` |
| 단계별 운동 처방 | `PROTOCOLS` (부위 × 단계 A/B/C/D, `core` 3개 + `extra`) |
| 운동 하는 법 설명 | `js/exercises.js` |
| 한 번에 보여줄 운동 수 | `RX_LIMITS` |
| 통증 유발 요인 목록 | `PAIN_TRIGGERS` |
| 매일 루틴 체크리스트 | `ROUTINE` |
| 혈액검사 항목·정상 기준 | `LAB_FIELDS` |
| 오늘의 미션 3개 | `coreMissions()` |
| 관리 모듈 | `MODULES` (앱 온보딩·설정에서도 선택) |
| 포인트 적립량·보너스 | `POINTS` |
| 보상 목록 기본값 | `DEFAULT_REWARDS` (앱 설정에서도 편집 가능) |
| 뱃지 종류 | `BADGES` + `js/rewards.js` 의 `badgeList()` |
| 시간대별로 묻는 항목 | `CHECKIN_SLOTS` + `js/checkin.js` |

## 구조

```
index.html              앱 셸
manifest.webmanifest    PWA 매니페스트 (설치, 바로가기)
sw.js                   오프라인 캐시
css/app.css             디자인 토큰(T13) + 전체 스타일 (다크 모드 포함)
DESIGN.md               시각 유형 지정서 — 디자인 작업 지시용
js/
  config.js      목표·부위·처방·루틴·검사 항목   ← 개인화는 여기
  store.js       localStorage 저장소, 백업/복원
  utils.js       날짜·통계(이동평균, 상관, 추정 HbA1c)·판정
  analysis.js    체중/혈당/검사/통증 요약, 상관 분석
  protocol.js    통증 점수 → 단계 → 처방 생성
  checkin.js     "지금 물어볼 것" 선별
  rewards.js     오늘의 미션 판정 · 연속일 · 포인트 · 뱃지 · 보상 교환
  labparse.js    검진 결과지 텍스트 → 숫자 추출 (병원별 표기 차이 흡수)
  install.js     홈 화면 설치 안내 (안드로이드 버튼 / 아이폰 수동 안내 / 설치 여부 판별)
  exercises.js   운동 31가지 하는 법 — 단계 · 맞는 느낌 · 흔한 실수 · 영상 검색어
  poses.js       자세 그림 12종 (여러 운동이 나눠 쓴다)
  profile.js     프로필에 따라 화면이 달라지는 지점(모듈·부위)
  chart.js       의존성 없는 SVG 차트 (호버 툴팁·범례·표 보기)
  ui.js          타일·배지·진행바·슬라이더·토스트
  app.js         라우팅·테마·알림·SW 등록
  views/         onboard · today · weight · glucose · pain · labs · report · summary · settings
vercel.json             베르셀 배포 설정 (캐시 · MIME · 보안 헤더)
.vercelignore           베르셀에 올리지 않을 문서·도구
moved/                  예전 GitHub Pages 주소에 올리는 안내 페이지 + 자폭 서비스워커
landing/                T13 구도까지 적용한 랜딩 페이지 (별도 지면)
  index.single.html     공유용 한 장짜리 (색·이미지까지 전부 들어 있음)
  build-single.py       한 장짜리를 다시 굽는 스크립트
PRODUCT.md              확장 설계 — 단계 · 수익 · 의료 경계선 · 측정 지표
assets/icons/    앱 아이콘
```

차트는 색만으로 정보를 전달하지 않는다. 계열마다 범례 + 끝점 라벨 + 모양(원/삼각/사각)을 함께 쓰고,
모든 그래프 아래에 **표로 보기**가 있다. 다크 모드는 자동 반전이 아니라 다크 배경에 맞춰 따로 고른 색을 쓴다.

## 면책

개인 기록·관리 도구다. 진단이나 치료를 대신하지 않는다.
통증이 2주 이상 이어지거나, 적색신호에 해당하거나, 혈당·지질 수치가 목표를 크게 벗어나면
기록을 들고 의료진과 상의할 것.
