# 페이지 구성 — 랜딩 페이지 / 원페이지 스크롤

**마이바디** · T13 소프트 3D 정물

히어로 한 컷 + 설명 + CTA. 첫 화면에서 읽히는 것이 전부다.

> **이 구성을 쓰는 때** — 기능이 3~5개고 한 번에 설득이 끝나는 서비스. 대부분 여기가 맞다.

페이지 1장 · 섹션 9개

**이 페이지가 됐는지 판정**

- [ ] 히어로 — 이 화면만 보고 무엇을 하는 서비스인지 말할 수 있나?
- [ ] 문제 — 읽는 사람이 '내 얘기네' 하나?
- [ ] 해결 3단 — 세 항목이 서로 다른 것을 말하나? 하나라도 겹치면 합친다
- [ ] 작동 방식 — 처음 보는 사람이 순서를 따라갈 수 있나?
- [ ] 증거 — 여기 있는 숫자와 이미지가 전부 실제인가? 하나라도 가짜면 섹션째 뺀다
- [ ] 요금 — 무료로 어디까지 되는지 한눈에 보이나?
- [ ] 자주 묻는 질문 — '안 됩니다'로 시작하는 답이 하나라도 있나? 없으면 솔직하지 않은 것이다
- [ ] 최종 CTA — 여기까지 읽은 사람이 다음에 뭘 해야 할지 아나?
- [ ] 푸터 — 법적으로 필요한 것만 있나?

## 이 지면에서 특히

- 유형의 구조(structure)를 섹션 순서 그대로 쓴다.
- 구도 초점 — 가장 큰 오브젝트
- 그림자 — 부유 높이별로 y12 blur28 10% ~ y28 blur52 7%. 높이가 다르면 그림자도 달라야 한다
- 이미지 비율 — 1:1 오브젝트 프레임

## 채울 때

1. '채울 것' 의 빈칸을 순서대로 채운다. 글자 수 제한은 권고가 아니라 상한이다.
   **▲** 표시가 그 섹션에서 시각적으로 가장 커야 하는 것이다. 위계를 임의로 바꾸지 않는다.
2. 페이지마다 붙은 판정 문장을 전부 통과시킨다. 하나라도 '아니오' 면 그 섹션을 다시 쓴다.
3. 섹션을 임의로 늘리지 않는다.
4. *(선택)* 섹션은 채울 내용이 없으면 **통째로 지운다.** 빈 섹션을 남기지 않는다.
5. 로렘입숨·가짜 수치·축 없는 차트 금지. 실제 내용이 없으면 그 섹션을 지운다.
6. `tokens.css` 의 토큰을 하드코딩 색으로 바꾸지 않는다.
